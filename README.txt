学園祭レジ スマホ接続画面 修正版

1. GitHubリポジトリのルートにある index.html を、このZIP内の index.html で置き換えてコミットします。
2. Pagesの公開完了後、SafariでURLを開き、ボタン名に「（修正版）」があることを確認してください。
3. 「スマホ表示を接続（修正版）」を押すと接続画面が前面に開きます。
4. 既存の sw.js / manifest.webmanifest は変更しないでください。
5. iPadとスマホのオフライン通信はWebRTC接続条件に左右され、動作保証はありません。

※ この更新ではlocalStorageのレジデータは削除しません。念のためJSONバックアップを取得してください。
