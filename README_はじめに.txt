学園祭レジ iPad + スマホ（オフラインWebRTC版）

【重要】これは実験的なローカルP2P接続です。通信サーバーは使いませんが、最初に両端末でHTTPSサイトを読み込み、オフラインキャッシュを確認する必要があります。端末やルーターの設定により接続できない場合があります。

1. このフォルダの index.html / sw.js / manifest.webmanifest をGitHub Pagesのリポジトリ直下にアップロードし、以前のファイルを置き換えます。GitHub Pagesは公開サイトです。売上やパスワードをリポジトリにアップロードしないでください。
2. インターネット接続中にiPadとスマホで公開URLを開きます。iPadは通常のレジURL、スマホは末尾に ?display=1 を付けたURLです。オフラインにする前に両端末でリロードし、機内モード + Wi-Fi再有効化でもページが開くことを確認します。キャッシュの初回登録や更新に失敗する場合はインターネット接続中に再読み込みしてください。
3. iPadとスマホを同じローカルWi-Fiに接続します。端末間通信を遮断するルーター設定（AP isolation / client isolation）は無効にしてください。
4. iPadのレジ画面「📡 スマホ表示を接続」→「接続用ファイルを作成」→「接続用ファイルを共有」で festival-offer.txt をスマホにAirDrop等で渡します。
5. スマホで「接続用ファイルを読み込む」→ 受け取った offer を選択 →「回答ファイルを共有」で festival-answer.txt をiPadへ送ります。
6. iPadで「スマホからの回答ファイルを読み込む」→ answer を選択します。接続完了後、商品や預かり金を変更するとスマホの金額が変わります。
7. AirDropで受け取ったファイルがSafariで開いてしまう場合は「ファイル」アプリに保存してからファイル選択で読み込んでください。

【制約】
・通信はブラウザのWebRTC DataChannelを利用し、外部STUN/TURNサーバーは使いません。Safari・iOS・Wi-Fi環境によって接続に失敗する場合があります。
・Safariがバックグラウンドに移動したり画面ロックすると通信が停止する場合があります。両端末の画面を点灯したまま使用してください。
・接続は再起動やWi-Fi変更で切れます。その際は2つのファイルを再交換してください。
・スマホ表示は会計金額とお釣りのみ受信し、ログインや売上データは受信しません。
・既存のiPadのローカル保存データは原則維持されますが、更新前にJSONバックアップを保存してください。Safariとホーム画面アプリで保存領域が異なる場合があります。
・本番利用前に実機で長時間の接続試験、会計、売上保存、バックアップ・復元を確認してください。
