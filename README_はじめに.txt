学園祭レジ iPad単体版
====================
Mac・Python・ローカルサーバーは不要です。ただし、iPadのSafariで安全にログイン機能とオフライン動作を利用するため、最初にHTTPSの静的サイトとして公開する必要があります。

【公開方法】
1. ZIPを解凍して index.html / sw.js / manifest.webmanifest を同じフォルダに置きます。
2. 静的サイトをHTTPSで配信できるサービス（例：GitHub Pages、Netlify Drop等）にこの3ファイルを公開します。
3. iPadのSafariで公開URLを開き、初回管理者アカウントを作成します。
4. Safariの共有メニュー→「ホーム画面に追加」。ホーム画面のアイコンから起動します。
5. 一度オンラインで開き、機内モードにしてホーム画面のアイコンから起動できるか確認してください。サービスワーカーのキャッシュが完了していればオフライン利用できます。

【重要】
・ブラウザのローカル保存領域に商品・取引・ID情報が保存されます。サーバーには送信しません。
・iPadのSafariとホーム画面アプリは保存領域が異なる場合があります。運用する起動方法を統一してください。
・iPadを変更したりSafariのサイトデータを消すとデータが失われることがあります。JSONバックアップとCSVを毎日保存してください。
・既存のMac版のデータは、管理者画面でJSONバックアップを出力し、iPad版で復元できます（商品・売上・割引設定）。アカウントは移行されないため、iPadで新規設定してください。
・「完全リセット」は保存したデータとアカウントを削除します。必ずバックアップしてください。
・ローカルのファイルを「ファイル」アプリで開く方式は、SafariのWeb Crypto/保存領域の制約があるため推奨しません。
・無料ホスティングで公開する場合、レジのHTMLプログラム自体は閲覧できる状態になります。ID/パスワードや売上データはブラウザ内保存ですが、公開先は自分が管理する信頼できるサービスを選び、URLを不用意に共有しないでください。
・本番前にオフライン起動・ログイン・会計・割引・CSV・バックアップ復元を必ず検証してください。
